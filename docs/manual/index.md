# 1. はじめに

Pergamum（ペルガモン）は、小説を書く人のための統合執筆環境です。本文を書くエディタと、人物・地名・用語などの作品情報を管理する道具を、一つのプロジェクトにまとめます。

まずは原稿を一つ作って、書いて保存してみてください。作品が長くなってきたら、語彙集や文書マップなど、必要な道具を少しずつ使っていけます。

原稿本文は Markdown ファイルとして保存します。Markdown は見出しなどを文字で書き表す形式で、他のテキストエディタでも読めます。作品情報や設定は本文とは別に管理します。

このマニュアルは、初めて原稿を書くところから代表的な機能を試すところまでを案内します。すべての機能・設定を説明するものではありません。画面名は日本語表示を基準にしています。
